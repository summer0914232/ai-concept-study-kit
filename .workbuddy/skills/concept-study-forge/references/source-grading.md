# 来源分级与取证规范

本文件是 `SKILL.md` 第 5 节的补充，供生成资料时快速判断「这条能不能引」。

## 一、分级判定

| 级别 | 判定标准 | 典型来源 | 在资料中的角色 |
| --- | --- | --- | --- |
| 一手 | 由概念的提出者 / 实现方 / 标准化组织发布 | arXiv 原始论文、ACL/IEEE 正式版、官方产品文档、协议规范（如 MCP）、发布方工程博客 | 支撑定义、机制、数字。必须 ≥1 条 |
| 二手 | 由第三方对一手来源做的系统性整理 | 综述论文（survey）、教科书、大学课程讲义、领域专家长文 | 交叉验证、通俗化解释 |
| 参考 | 可靠性依赖社区维护 | 百科条目、行业报告、问答社区高赞回答 | 仅限背景与术语，**不可作为唯一依据** |
| 禁用 | — | 无署名营销稿、SEO 内容农场、无法访问的链接、AI 凭空生成的「看起来像真的」引用 | 发现即作废 |

### 判定口诀

- **谁发布的** ＞ **在哪发布的**。同一篇内容，作者本人的工程博客优于二手转载。
- **能否被第三方复现** 是划分一手/二手的实用标准：给出方法、数据、代码的可复现材料算一手。
- **时效性单独判断**：一手不代表最新。2017 年的 Transformer 论文是一手，但描述当下模型能力时不能只引它。

## 二、验活流程

生成资料前，对每一条候选链接执行：

```bash
curl -s -o /dev/null -L -w "%{http_code}  %{url_effective}\n" --max-time 20 "<URL>"
```

- `200` → 保留
- `301 / 302` 且 `url_effective` 最终为 `200` → 保留，并在资料中写最终可达地址
- `403 / 404 / 000` / 超时 → **弃用**，换源

### 网络受限时的处理

若本机代理拦截了部分域名（表现为 `HTTP/1.1 502 Bad Gateway` 或 `000`），
可尝试绕过代理直连后再判定：

```bash
curl -s -o /dev/null -L -w "%{http_code}\n" --noproxy '*' --max-time 20 "<URL>"
```

仍然不可达的链接，一律不写入资料。**「我之后再去验证」等同于编造来源**——
评审者看到的是一个可点击的链接，无法区分它是否经过验证。

## 三、正文标注规范

| 标签 | 含义 | 规则 |
| --- | --- | --- |
| `[事实]` | 有已验证来源支撑 | 必须在来源表中能找到对应条目 |
| `[推断]` | 由 ≥2 条事实推得 | 必须写出推理链，不能只给结论 |
| `[我的判断]` | 个人观点 | 必须给出理由，且允许被反驳 |

同一段落混用多种陈述时，按最小粒度拆开标注，不要整段贴一个标签。

## 四、常见失败模式（自检时重点排查）

1. **挂羊头式引用**：来源表列了权威链接，但正文那句话其实来自模型自身记忆
2. **僵尸链接**：链接在生成时已失效，或指向站内搜索页 / 首页充数
3. **数字漂移**：引用模型参数量、上下文长度等易变数字却不标日期
4. **一手缺失**：全部来源都是二手教程，定义部分缺乏原始依据
5. **标签缺位**：整页没有一处 `[推断]` / `[我的判断]`，说明只是在复述，没在理解
